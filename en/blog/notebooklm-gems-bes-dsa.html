NotebookLM or Gemini Gems for Special Needs? A Practical Guide

It's the question colleagues ask me most often after a training course: "Should I use NotebookLM or Gems?" The short answer: they're not the same thing, and used together they do more than either does alone.

I've tested both for months on the same materials — history texts, science, tests — with the same students. What follows is the method I actually use, not a feature list copied from the official documentation.

The difference that actually matters

A Gem is a persistent assistant inside Gemini: the instructions stay active forever, so you don't have to repeat every time "this student has dyslexia, use short sentences, add a glossary." You write it once, then call up the Gem every week.

NotebookLM, on the other hand, starts from a document — a textbook chapter, your own handout, a PDF — and lets you work on it in chat, generating different materials from the same source.

The mental shortcut I use: the Gem transforms a text, NotebookLM makes it available in many different formats. They're complementary, not alternatives.

Building a Gem that never forgets the rules

The problem a Gem solves isn't "how do you adapt a text" — it's that re-explaining it every time to a normal chat wastes time and, over the long run, makes you skip a rule here and there. A Gem, instead, carries the instructions with it, always active.

A real excerpt from the instructions I use for text adaptation:

You are an inclusive education expert specializing in learning disabilities, special needs and disabilities.
When you receive a text, produce:
- Adapted text: short sentences (max 20 words), one concept per paragraph,
  key words in bold
- Glossary: 6-8 difficult words with a simple definition at the end

Rules always active:
- Keep ALL the concepts from the original text — simplify the form, not the content
- If the profile indicates ASD, add explicit structure: numbering, zero metaphors
- If the profile indicates ADHD, split into short sections with visible headings

From that point on, for every text you just need to write: "Text for a student with moderate dyslexia, struggles with long texts" — and the Gem automatically applies all the configured rules, with no need to rewrite them.

NotebookLM: the same document, seven different outputs

The thing I discovered by accident, and that changed how I work, is this: if you upload to NotebookLM the text already adapted by the Gem — not the original — the quality of everything it generates afterward improves noticeably. Audio, quizzes and summaries inherit the same simplified vocabulary and the same analogies from the source text.

For a student with severe dyslexia, the Audio Overview is probably the single most useful feature: two voices conversing about the main concepts, short format, so the student listens instead of reading. I've seen the difference in the classroom — material that used to be ignored, listened to all the way through.

Even the quiz generated by NotebookLM has a detail worth knowing: if the source text uses a concrete analogy (e.g. "evaporation is like water boiling in a pot"), that analogy automatically reappears in the hints under each question — because the quiz inherits the vocabulary of the uploaded source.

Storybook: when you need a story, not a worksheet

There's a category of need that neither the Gem nor NotebookLM covers well: social stories for students on the autism spectrum — short, visual narratives that anticipate a situation or a routine (arriving at school, changing classes, a new event).

For that I use Gemini Storybook: you describe the sequence in natural language ("wake up → breakfast → backpack ready → bus → school entrance") and get a 10-page illustrated book with narrated audio, downloadable as a PDF to print or as a video for independent listening on a tablet.

What doesn't work well, to be honest

The automatic visual generation features (infographics, presentations from NotebookLM's dedicated menu) still produce frequent errors in my experience. For diagrams I prefer to have the Gem generate a text image prompt to paste separately into Gemini's "Create image" feature — slower than one click, but far more reliable.

The practical rule I use every week: if I do the same thing more than twice, I turn it into a Gem. If I'm working on a document that already exists, I use NotebookLM. Neither replaces the other.

Frequently Asked Questions

What's the difference between NotebookLM and Gemini Gems?
A Gem is a persistent assistant: the instructions stay active forever, useful when you adapt the same type of text every week. NotebookLM instead starts from an uploaded document (a chapter, a handout) and turns it into multiple formats — audio, quizzes, summaries. In short: the Gem transforms a text, NotebookLM makes it available in many formats.

Can NotebookLM and Gems be used together for special-needs materials?
Yes, and the combination works better than either tool alone: uploading the text already adapted by the Gem into NotebookLM — not the original — noticeably improves the quality of everything NotebookLM generates afterward, because the audio, quizzes and summaries inherit the same simplified vocabulary.

What is NotebookLM's Audio Overview useful for with a student who has dyslexia?
It generates a short audio conversation between two voices about the main concepts in the uploaded document. For a student with severe dyslexia it's often the most useful feature: it lets them listen instead of read, with vocabulary consistent with the source text.

How do you create a social story for a student on the autism spectrum?
With Gemini Storybook: you describe the sequence in natural language (e.g. "wake up → breakfast → backpack ready → bus → school entrance") and get a 10-page illustrated book with narrated audio, downloadable as a PDF or as a video for independent listening.
