Bachata Vibes Publisher

Desktop application for publishing original latin music videos to TikTok

About

Bachata Vibes Publisher is a desktop content management tool developed by Bachata Vibes Music. It enables the @bachatavibesmusic TikTok account to publish original bachata, salsa, and merengue music videos directly from a local library of pre-produced content.

The app is used exclusively by the Bachata Vibes Music team to manage and schedule video uploads to TikTok. No third-party users or external data are involved.

Features

OAuth 2.0 Authentication

Secure login via TikTok's Login Kit with PKCE flow. Only the channel owner authorizes the app.

Video Upload

Uploads MP4 videos (1080x1920, H.264/AAC) via the TikTok Content Posting API with chunked file transfer.

Batch Publishing

Processes multiple videos with automatic rate limiting, title generation, and hashtag management.

Content Management

Tracks upload history, prevents duplicates, and manages video metadata locally.

TikTok Integration

The app integrates with the following TikTok for Developers products:

  • Login Kit — Authenticates the account owner via OAuth 2.0
  • Content Posting API — Uploads and publishes video content to the authorized TikTok profile
