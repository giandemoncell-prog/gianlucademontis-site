Privacy Policy

Last updated: April 6, 2026

1. Introduction

Bachata Vibes Publisher ("the App") is a content publishing tool operated by Bachata Vibes Music. This privacy policy explains how we handle data when using the TikTok Content Posting API.

2. Data We Collect

Data TypePurposeStorage
TikTok Access TokenAPI authentication for publishingLocal file, encrypted
TikTok Open IDIdentify authorized accountLocal configuration file
Publication LogTrack published content, prevent duplicatesLocal JSON file
Video MetadataTitles, descriptions, hashtags for uploadsLocal JSON file

3. Data We Do NOT Collect

  • Personal information of TikTok viewers or followers
  • TikTok analytics or user engagement data beyond what we publish
  • Comments, messages, or interactions from other users
  • Location data, device information, or browsing history
  • Any data from users other than the authorized account owner

4. How We Use Data

All collected data is used exclusively for:

  • Authenticating with the TikTok API to publish content
  • Scheduling and managing video uploads
  • Preventing duplicate publications
  • Maintaining a log of published content

5. Data Storage and Security

All data is stored locally on the operator's computer. No data is transmitted to third-party servers other than TikTok's API endpoints. Access tokens are stored in environment files with restricted file system permissions.

6. Data Sharing

We do not sell, share, or transfer any data to third parties. The only external communication is with TikTok's API servers for the purpose of publishing content.

7. Data Retention

Access tokens are retained until they expire or are manually revoked. Publication logs are retained indefinitely for record-keeping purposes. Users can request deletion of all stored data at any time.

8. User Rights

The authorized TikTok account owner can at any time:

  • Revoke the App's access through TikTok settings
  • Request deletion of all locally stored data
  • Review what data is stored

9. Children's Privacy

The App is not intended for use by children under 13. We do not knowingly collect data from children.

10. Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected on this page with an updated date.
