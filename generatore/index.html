Come si usa

python -m venv venv
venv\Scripts\activate          # Windows  (Mac/Linux: source venv/bin/activate)
pip install -r requirements.txt
python generatore.py --studente mario --testo testi/testo_prova.txt

La chiave Gemini va in un file .env nella stessa cartella (GEMINI_API_KEY=la_tua_chiave). Si ottiene gratis su aistudio.google.com/apikey. Profili, cartelle e opzioni sono spiegati passo per passo nell'Appendice E.

Privacy: anche con il generatore locale il testo da adattare viene inviato all'API di Google. Non inserire mai nomi, cognomi o dati sanitari degli studenti: usa testi didattici e profili anonimi. Con l'opzione Ollama della versione Pro, invece, i dati restano sul tuo computer.
